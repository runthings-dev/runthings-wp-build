# Steps for building

update CHANGELOG.md

commit "docs(changelog): update for vx.x.x"

npm-version x.x.x

commit "chore(release): deploy vx.x.x"

npm login

npm publish

git tag v3.2.0 && git push --tags

log release on timeline eg:

7th-February-2026 - Released NPM Package - v3.3.0 - RunThings WP Build - https://github.com/runthings-dev/runthings-wp-build/releases/tag/v3.3.0
